# Interface fonts

Geist Sans (variable), Geist Mono (variable), and Geist Pixel Square are self-hosted
so the editor does not need an external font service. All use `font-display: swap`.

Source: [Vercel Geist](https://github.com/vercel/geist-font/tree/75d647056bcbd9eaba3a14b1b58290d0692685d6),
commit `75d647056bcbd9eaba3a14b1b58290d0692685d6`.
The original files are `fonts/Geist/webfonts/Geist[wght].woff2`,
`fonts/GeistMono/webfonts/GeistMono[wght].woff2`, and
`fonts/GeistPixel/webfonts/GeistPixel-Square.woff2`.

The SIL Open Font License is included in [OFL.txt](OFL.txt). Fonts apply only to
the editor interface; map and export text continue to use their existing fonts.
